Accuracy is not enough: chest X-ray pneumonia detection

Three CNNs compared on the real RSNA Pneumonia Detection dataset (26,684 X-rays). The deeper model had the higher accuracy, and still missed most pneumonia cases. Which model "wins" depends on which metric you rank by.

0.838AUC, MobileNetV2 transfer learning
0.85pneumonia recall, MobileNetV2
0.39pneumonia recall of the higher-accuracy Deep CNN

Not claimed: clinical usefulness. This is a model comparison, not a diagnostic tool.

Accuracy is not Enough: Why Two "Good" Models Disagree on Which One is Best

Which model wins depends on whether you rank by accuracy or by the recall of the class that matters. In pneumonia screening, those two rankings point in opposite directions.
